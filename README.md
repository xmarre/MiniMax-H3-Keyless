# MiniMax-H3-Keyless

Production design work for a Keyless Attention derivative of `xmarre/MiniMax-H3-Pruned-Ref-Delta-Fused-r1024-ComfyUI`, with a BF16 teacher/student path and INT8 ConvRot deployment.

The architecture and ecosystem audit is in progress. No runtime implementation or trained Keyless checkpoint is available. The planned authoritative specification is `docs/KEYLESS_H3_IMPLEMENTATION_DESIGN.md`.
